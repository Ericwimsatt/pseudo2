# Phase 2: TreeBoxLayer — rewrite NodeLayer.tsx as nested bordered boxes

## Context

In Phase 1, the layout was converted to CSS Grid with a fixed icon column. Now we replace the `NodeLayer` (which renders translation nodes with simple `paddingLeft`-based indentation) with a `TreeBoxLayer` that renders nested bordered boxes.

The `DisplayNodeData[]` array is flat but has an `indent` field representing nesting depth. We convert it to a tree structure and render recursively with visual boxes.

## What to do

### 1. Create `buildTree` utility

In a new file `src/App/components/nodes/buildTree.ts`:

```ts
import type { DisplayNodeData } from '../../../main/translationService/renderable/types';

export interface TreeNode {
  node: DisplayNodeData;
  children: TreeNode[];
}

export function buildTree(nodes: DisplayNodeData[]): TreeNode[] {
  const root: TreeNode[] = [];
  const stack: { tree: TreeNode[]; indent: number }[] = [{ tree: root, indent: -1 }];

  for (const node of nodes) {
    const entry: TreeNode = { node, children: [] };
    while (stack.length > 1 && stack[stack.length - 1].indent >= node.indent) {
      stack.pop();
    }
    stack[stack.length - 1].tree.push(entry);
    stack.push({ tree: entry.children, indent: node.indent });
  }

  return root;
}
```

This walks the flat array sequentially. When a node has `indent` greater than the current parent, it becomes a child. When `indent` is same or less, we pop the stack until we find the right parent.

### 2. Create `TreeBox.tsx`

New file `src/App/components/nodes/TreeBox.tsx`:

```tsx
import type { TreeNode } from './buildTree';
import { DisplayNode } from './DisplayNode';

interface TreeBoxProps {
  treeNode: TreeNode;
  depth: number;
  isLast: boolean;
}

export function TreeBox({ treeNode, depth, isLast }: TreeBoxProps) {
  const node = treeNode.node;
  const hasChildren = treeNode.children.length > 0;

  // Depth-based border colors using inline styles (avoids extra CSS/Tailwind):
  const borderColors = ['#93c5fd', '#86efac', '#fde68a'];
  const bgColors = ['#f0f9ff', '#f0fdf4', '#fffbeb'];
  const color = borderColors[Math.min(depth, borderColors.length - 1)];
  const bg = bgColors[Math.min(depth, bgColors.length - 1)];

  // No border for leaf (childless) nodes — just text with indent
  if (!hasChildren) {
    return (
      <div
        className="whitespace-pre-wrap break-words leading-5"
        style={{ paddingLeft: depth > 0 ? 16 : 0 }}
      >
        <DisplayNode node={node} />
      </div>
    );
  }

  return (
    <div
      className="rounded-sm"
      style={{
        border: `2px solid ${color}`,
        borderBottom: isLast ? `2px solid ${color}` : 'none',
        margin: '2px 0',
        marginLeft: depth > 0 ? 16 : 0,
        background: bg,
      }}
      data-tree-depth={depth}
    >
      <div className="px-2 py-0.5 leading-5 min-h-[1.25rem] whitespace-pre-wrap break-words font-mono text-sm">
        <DisplayNode node={node} />
      </div>
      {hasChildren && (
        <div className="flex flex-col">
          {treeNode.children.map((child, i) => (
            <TreeBox
              key={i}
              treeNode={child}
              depth={depth + 1}
              isLast={i === treeNode.children.length - 1}
            />
          ))}
        </div>
      )}
    </div>
  );
}
```

**Key design rules:**
- **Leaf nodes** (no children) → render as flat text, no border, just left padding
- **Parent nodes** (has children) → draw border box with header + children container
- **Depth 0** → blue border (`#93c5fd`), blue tint background
- **Depth 1** → green border (`#86efac`)
- **Depth 2+** → amber border (`#fde68a`)
- **marginLeft: 16px** on each successive depth level
- **Last child** gets bottom border (closes the box); non-last children are open-bottom
- Children are in a `flex-col` container with no gap (tight packing)

### 3. Rewrite `NodeLayer.tsx` → `TreeBoxLayer.tsx`

Replace the content of `src/App/components/nodes/NodeLayer.tsx`:

```tsx
import type { DisplayNodeData } from '../../../main/translationService/renderable/types';
import { buildTree } from './buildTree';
import { TreeBox } from './TreeBox';

interface LayerProps {
  nodes: DisplayNodeData[];
}

export function NodeLayer({ nodes }: LayerProps) {
  if (nodes.length === 0) {
    return <div className="text-gray-300 italic">—</div>;
  }

  const tree = buildTree(nodes);

  return (
    <div>
      {tree.map((tn, i) => (
        <TreeBox
          key={i}
          treeNode={tn}
          depth={0}
          isLast={i === tree.length - 1}
        />
      ))}
    </div>
  );
}
```

**Important:** Keep the component name as `NodeLayer` and the export as `NodeLayer` — `LineRow.tsx` and other files import it by that name. Only the internal implementation changes.

### 4. Keep empty previous files

- `PlainNodeLayer.tsx` in the same directory is used by tooltips and should NOT be changed
