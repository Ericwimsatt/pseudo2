# Phase 3: Update test selectors for new grid DOM structure

## Context

Phases 1 and 2 changed the DOM structure from `<table>`/`<tr>`/`<td>` to `<div>`-based CSS Grid with `.code-grid` classes and `[data-line]` attributes on source cells instead of rows. All tests that query the DOM need their selectors updated.

The pure function tests (`computeMatches`, `dedupMatches`, `parentIndices`) do NOT need changes.

## What to do

### 1. Update `test/integration/CodeTable.integration.vitest.tsx`

The last four tests (the rendering tests in the `'CodeTable rendering'` describe block) use DOM queries that need updating:

**Test: 'renders a table with rows for each source line'**
```tsx
// OLD:
const table = document.querySelector('table');
expect(table).toBeTruthy();
const rows = table?.querySelectorAll('tbody tr');

// NEW:
const grid = document.querySelector('[class*="w-full font-mono"]');
expect(grid).toBeTruthy();
// Or, use a simpler check: look for any element with data-line
const rows = grid?.querySelectorAll('[data-line]');
expect(rows?.length).toBeGreaterThan(0);
```

**Test: 'renders line numbers for each row'**
```tsx
// OLD:
const line1 = document.querySelector('tr[data-line="1"]');

// NEW:
const line1 = document.querySelector('[data-line="1"]');
```

**Test: 'applies bucket classes to rows'**
```tsx
// OLD:
const rows = document.querySelectorAll('tr[data-bucket]');

// NEW:
const rows = document.querySelectorAll('[data-bucket]');
```

**Test: 'renders the filename in the header'** — no change needed (uses `screen.getByText`).

### 2. Update `test/integration/LineRow.integration.vitest.tsx`

The `renderRow` helper wraps `LineRow` in `<table><tbody>` — this must change since `LineRow` now returns a fragment (not a `<tr>`).

**New `renderRow` helper:**
```tsx
function renderRow(line: LineRenderable, overrides: Record<string, any> = {}) {
  return render(
    <div style={{ display: 'grid', gridTemplateColumns: '6px 48px 1fr 4px 20px 1fr' }}>
      <LineRow
        line={line}
        lineIndex={0}
        rowNum={1}
        bucketStyle={BUCKET_STYLES[line.bucket]}
        isInterface={false}
        onResizeStart={vi.fn()}
        {...overrides}
      />
    </div>
  );
}
```

**Test: 'applies bucket class to the row'**
```tsx
// OLD:
const row = document.querySelector('tr');

// NEW: bucket class is on the source cell (column 3)
const sourceCell = document.querySelector('[data-bucket]');
expect(sourceCell?.className).toContain('bg-amber-50/60');
```

**Test: 'applies rowSpan attribute to translation cell when defined'**
```tsx
// OLD:
const cells = document.querySelectorAll('td');
const transCell = cells[cells.length - 1];
expect(transCell?.getAttribute('rowspan')).toBe('3');

// NEW: translation cell is grid-column 6, check gridRow for span
const transCell = document.querySelector('[style*="grid-column: 6"]');
expect(transCell).toBeTruthy();
// Or, check that the style contains "span 3"
const style = transCell?.getAttribute('style');
expect(style).toContain('span 3');
```

**Test: 'shows nbsp for empty source text'**
```tsx
// OLD:
expect(document.querySelector('tr')).toBeTruthy();

// NEW: just check that any element renders (the source cell)
expect(document.querySelector('[data-line]')).toBeTruthy();
// Or check the source cell
expect(document.querySelector('[style*="grid-column: 3"]')).toBeTruthy();
```

**Other tests in this file:** These use `screen.getByText()` or `document.querySelectorAll('mark')` which don't depend on the table structure — they should work without changes. Verify they pass and only modify if they fail.

### 3. Update `test/e2e/hover.spec.ts`

**Function `hoverable`:**
```tsx
// OLD:
page.locator('table tbody td:last-child span.cursor-help')

// NEW:
page.locator('[style*="grid-column: 6"] span.cursor-help')
// OR just: (simpler)
page.locator('span.cursor-help')
```

The `span.cursor-help` approach works if there aren't other `cursor-help` spans outside the translation column. The translation column is the only place `StyledSpan` renders with `cursor-help`. Prefer `'[style*="grid-column: 6"] span.cursor-help'` to be precise.

**Popover test:**
```tsx
// OLD:
page.locator('table tbody td:last-child')

// NEW:
page.locator('[style*="grid-column: 6"]')
```
