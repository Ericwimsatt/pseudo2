Nested Tree Boxes (replace NodeLayer.tsx)
Each semantic node becomes a bordered box containing its children. Collapse toggles display: none on .tree-box-children. Fixed 20px icon column keeps tree content aligned across all rows.

⛔ Broken vertical lines FIXED

Boxes are single DOM elements — no line segments to break. A blank source line between blocks just means two adjacent boxes with no connection needed.

⛔ Wrapping not indented FIXED

Text wraps inside .tree-box-header. The box borders naturally grow with content. No inline tree-line spans that can't expand.

⛔ Gaps between lines FIXED

Children render as direct DOM children of the parent box. No spacing gaps between tree elements. Use gap explicitly if desired.

⛔ Icon shift alignment FIXED

Icons live in a dedicated 20px column (grid-column: 5). Every grid row has this column — even if empty. Tree content always starts at the same x position.
